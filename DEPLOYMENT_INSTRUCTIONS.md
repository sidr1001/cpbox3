## 🧪 Тестирование

### 1. Тест публикации в VK

1. Подключите VK аккаунт в настройках
2. Создайте пост с текстом
3. Выберите VK платформу
4. Опубликуйте пост
5. Проверьте, что пост появился в VK и статус изменился на "published"

### 2. Тест отображения подключенных аккаунтов

1. Перейдите в настройки
2. Убедитесь, что VK подключен

4. Проверьте, что показываются правильные права доступа

## 🚨 Возможные проблемы

### 1. Ошибка "VK API error: Invalid access_token"

**Причина**: Неверный или истекший токен VK
**Решение**: Переподключите VK аккаунт в настройках

### 2. Ошибка "Failed to get VK user info"

**Причина**: Проблемы с Edge Function или API VK
**Решение**: Проверьте логи функции и убедитесь, что домены правильные

### 3. Пост не публикуется в VK

**Причина**: Недостаточные права доступа или проблемы с API
**Решение**: Проверьте права доступа в VK и убедитесь, что токен действителен

## 📞 Поддержка

При возникновении проблем:

1. Проверьте логи Edge Functions
2. Убедитесь, что все секреты настроены правильно
3. Проверьте права доступа в VK приложении
4. Обратитесь к документации VK API
